公司人事管理制度

第一条：工作时间
1. 正常工作时间：周一至周五，上午9点至下午6点。
2. 午休时间：12点至13点。
3. 加班需提前申请，加班费按1.5倍计算。
4. 法定节假日加班按3倍计算。

第二条：年假制度
1. 工作满1年不满3年：年假5天。
2. 工作满3年不满10年：年假10天。
3. 工作满10年以上：年假15天。
4. 年假需提前3天申请，经上级审批。

第三条：请假制度
1. 病假：需提供医院证明，工资按80%发放。
2. 事假：需提前1天申请，工资不发放。
3. 婚假：7天，工资正常发放。
4. 产假：女员工180天，男员工陪产假15天。

第四条：薪资制度
1. 薪资每月15日发放。
2. 试用期薪资为正式薪资的80%。
3. 年终奖根据绩效考核结果发放。
4. 社保按国家规定缴纳。
