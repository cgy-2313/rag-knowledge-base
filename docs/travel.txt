公司差旅报销制度

第一条：适用范围
本制度适用于公司全体员工因公出差产生的相关费用报销。

第二条：交通费用
1. 火车出行：员工可购买高铁二等座，特殊情况经审批可购买一等座。
2. 飞机出行：出差距离超过800公里可乘坐经济舱，需提前3天申请审批。
3. 打车费用：市内交通每天限额100元，超出部分自理。
4. 私家车出行：按实际里程每公里补贴0.8元，需提供行驶记录。

第三条：住宿费用报销标准
出差期间住宿费用按城市等级报销，广州属于一线城市。
1. 一线城市（北京、上海、广州、深圳）：每晚住宿限额500元。
2. 二线城市：每晚住宿限额350元。
3. 其他城市：每晚住宿限额250元。
4. 住宿需提供正规发票，不接受收据。

第四条：餐饮费用
1. 早餐补贴：每天30元。
2. 午餐补贴：每天60元。
3. 晚餐补贴：每天80元。
4. 每日餐饮补贴合计不超过150元。

第五条：报销流程
1. 出差结束后5个工作日内提交报销申请。
2. 填写差旅报销单，附上所有票据原件。
3. 直属上级审批后提交财务部门。
4. 财务审核通过后3个工作日内打款。

第六条：注意事项
1. 所有票据必须是出差期间产生，日期需与出差时间匹配。
2. 酒精类饮品不予报销。
3. 个人娱乐消费不予报销。
4. 超出标准的费用需总经理审批。
